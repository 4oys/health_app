# Поэтапная сдача проекта «Здоровье»

Ветка `main` содержит готовую на текущий момент версию. Все перечисленные этапы уже есть в истории Git. Для каждого этапа открывайте ссылку на соответствующий коммит: она показывает состояние проекта на тот момент. Не нужно удалять готовый код или переписывать историю, чтобы показать промежуточные результаты.

| Этап | Версия проекта | Что показать преподавателю |
| --- | --- | --- |
| 1. Основа и данные | [6d800f0](https://github.com/4oys/health_app/tree/6d800f0) | Структура Flutter для Android и iOS, тема, модели пользователя и продуктов, SQLite, расчёты КБЖУ и ИМТ. Макеты лежат в корне проекта. |
| 2. Вход и главная | [318e873](https://github.com/4oys/health_app/tree/318e873) | Регистрация и локальный вход, приветствие, баланс калорий, БЖУ, активность и приёмы пищи. |
| 3. Дневник питания | [47698a0](https://github.com/4oys/health_app/tree/47698a0) | Выбор дня, секции приёмов пищи, карточки продуктов, добавление порции, поиск по локальной базе и экран сканирования. |
| 4. Аналитика и профиль | [c16eb5d](https://github.com/4oys/health_app/tree/c16eb5d) | ИМТ, график веса, сон, PDF-отчёт, редактирование параметров и навигация между четырьмя вкладками. |
| 5. Интеграции | [ae47dba](https://github.com/4oys/health_app/tree/ae47dba) | Поиск и штрихкоды Open Food Facts, системные данные здоровья, локальные уведомления и вход через Apple на iOS. |
| 6. Проверка и доработка | [11ea5a2](https://github.com/4oys/health_app/tree/11ea5a2) | Обработка ошибок поиска, быстрый выбор продуктов, фоновая синхронизация, многостраничный PDF и проверка компоновки. |

Если преподаватель просит сдавать **каждый экран отдельно**, в истории есть отдельные коммиты: [авторизация](https://github.com/4oys/health_app/tree/3ec624e), [главная](https://github.com/4oys/health_app/tree/318e873), [дневник](https://github.com/4oys/health_app/tree/47698a0), [аналитика](https://github.com/4oys/health_app/tree/46d9aca), [профиль](https://github.com/4oys/health_app/tree/262170e).

Если преподаватель не дал шаблон отчёта, к каждому этапу приложите ссылку на версию, несколько снимков экрана и короткое описание: что реализовано, какие данные используются и как проверить результат. Для актуальной версии команды проверки: `flutter analyze`, `flutter test`, `flutter run` на Android. Сборка iOS и работа Apple Health/входа через Apple требуют macOS и проверки на iPhone; отдельное сопряжение смарт-часов в приложении не реализовано.
