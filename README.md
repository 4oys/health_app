# Здоровье

Мобильное приложение на Flutter для учёта питания, веса и активности. Интерфейс построен по PNG-макетам в корне проекта. Экран входа, главная, дневник, аналитика и профиль расположены в `lib/features`; общие модели, расчёты и SQLite-репозиторий — в `lib/features/health`.

## Запуск

Установите Flutter SDK и Android SDK либо откройте iOS-проект на macOS. Затем выполните:

```sh
flutter pub get
flutter run
```

Проверки: `dart analyze lib test` и `flutter test`.

## Данные

При первом запуске создаются пример профиля Александра, продукты, записи питания, история веса и активности. Данные хранятся в SQLite на устройстве. Вход по электронной почте и паролю локальный; секрет хранится в защищённом хранилище платформы. Записи питания и аккаунт можно удалить. Экспорт PDF работает без сетевого шрифта.

Поиск продуктов и сканирование штрихкодов используют Open Food Facts. Локальные совпадения появляются сразу; быстрые фильтры помогают найти часто используемые продукты. Доступные продукты можно добавить в дневник; после выбора они сохраняются локально. При отсутствии сети остаётся локальный каталог, а неизвестный штрихкод можно добавить вручную.

В профиле можно разрешить чтение шагов, пульса и фаз сна из Health Connect (Android 8.0+) или Apple Health (iOS 15+). Синхронизация требует установленного и настроенного системного источника данных, а также разрешений пользователя. При запуске сначала показываются сохранённые данные, затем показатели обновляются в фоне. Если измерений за день нет, экран сообщает об этом; отдельное сопряжение часов в приложении не реализовано. iOS-сборка требует включить HealthKit capability и настроить подпись в Xcode.

Переключатель уведомлений включает ежедневные локальные напоминания о питании в 12:00 и 19:00 по часовому поясу устройства. На Android 13+ и iOS приложение запрашивает системное разрешение. На iPhone вход через Apple открывает нативную авторизацию и сохраняет только локальную сессию. Для проверки на устройстве нужен App ID с возможностью Sign in with Apple и подпись в Xcode. Проект не имеет backend: серверная проверка Apple-токенов и сессии для нескольких устройств не реализована; на Android кнопка объясняет ограничение.

Шрифт PDF Noto Sans распространяется по лицензии OFL, текст лицензии находится в `assets/OFL.txt`.
